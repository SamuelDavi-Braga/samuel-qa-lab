# BUG-001 — Expansão indevida do cartão adjacente

**Projeto:** QA Engineering Lab  
**Módulo:** Explorador de Casos de Teste  
**Tipo:** Defeito de interface / Layout  
**Severidade:** Baixa  
**Prioridade sugerida:** Média  
**Status:** Resolvido — Reteste aprovado  
**Data do registro:** 26/10/2026  
**Responsável pela validação:** Samuel Braga

## 1. Descrição do defeito

Ao expandir os detalhes de um cartão no Explorador de Casos de Teste, o cartão adjacente também aumentava de altura, mesmo sem ter seus detalhes abertos.

O comportamento provocava uma expansão visual indevida e prejudicava a consistência da interface.

## 2. Pré-condições

- Aplicação executada localmente.
- Explorador de Casos disponível.
- Dois ou mais cartões apresentados lado a lado.

## 3. Passos para reprodução

1. Acessar o laboratório de Testes Funcionais.
2. Localizar os cartões CT-002 e CT-012.
3. Clicar em "Ver detalhes" no cartão CT-012.
4. Observar a altura do cartão CT-002.

## 4. Resultado esperado

Somente o cartão selecionado deve expandir para apresentar seus detalhes. Os cartões adjacentes devem manter a altura correspondente ao próprio conteúdo.

## 5. Resultado encontrado

O cartão CT-002 acompanhava a altura do CT-012, mesmo sem apresentar conteúdo expandido.

## 6. Investigação técnica

O CSS Grid utilizava o comportamento padrão de alinhamento que estica os itens para preencher a altura da linha.

A primeira tentativa de correção não resolveu o comportamento em telas maiores porque `align-items: start` havia sido aplicado somente dentro da media query de até 768px.

## 7. Correção aplicada

A propriedade `align-items: start` foi incluída na regra principal `.lista-casos`.

Também foi ajustada a responsividade para apresentar os cartões em uma coluna em telas menores.
